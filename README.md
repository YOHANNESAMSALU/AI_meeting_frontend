
  # AI Meeting Notes UI Design

  This is a code bundle for AI Meeting Notes UI Design. The original project is available at https://www.figma.com/design/nO2lDFW9ThdetkyCQPLLem/AI-Meeting-Notes-UI-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  The backend API is deployed and available at `https://ai-meeting-backend-dvt7.onrender.com`.
  The frontend is configured to use `NEXT_PUBLIC_API_URL=https://ai-meeting-backend-dvt7.onrender.com` by default.

  Run `npm run dev` to start the frontend.
